## 🚀 How to Use

1. **Download all files** from the owo-bot folder
2. **Install Node.js** (v16+) and MongoDB
3. **Run:** `npm install`
4. **Configure:** Copy `.env.example` to `.env` and add your bot token
5. **Start:** `npm start`

Full instructions in `SETUP_GUIDE.md`!
